# Seeds for failure cases proptest has generated in the past. It is
# automatically read and these particular cases re-run before any
# novel cases are generated.
#
# It is recommended that this file is checked in to source control so that
# everyone who runs the test benefits from these saved cases.
#
# NOTE: The payment amount strategy is now bounded to the realistic USDC
# range 0..=1_000_000_000_000_000i128 (1 billion USDC in stroops) so that
# fee calculations (e.g. 1% platform fee) cannot overflow i128. Negative
# amounts are exercised by a separate strategy and are expected to fail
# with InvalidAmount. The previously recorded seed below used an unbounded
# amount and is no longer reproducible under the bounded strategy, so it
# has been removed to avoid re-running an obsolete case.
